**API EXPLORER**

API Explorer is part of my "No AI challenge" where I have to build a bunch of projects without the use or assistance of an LLM (at least until all project requirements are met).

*What does API Explorer do?*
API Explorer is the generic name of the project. I chose the **REST Countries API**, a big library of information regarding countries and their characteristics. The user can search for a country through the dynamic searchbar and instantly obtain related information about it.
